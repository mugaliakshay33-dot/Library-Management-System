# Library Management System

## Description

A simple Library Management System developed using Python. This project helps users manage library books through a menu-driven command-line interface.

## Features

* Add new books
* Display all books
* Search books by title or author
* Issue books
* Return books
* Delete books
* Store records using JSON for data persistence

## Technologies Used

* Python 3
* JSON
* File Handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python library_management.py
